# Courses And Students Management System

A web-based management system developed to handle students, courses, and enrollment operations efficiently.  
The project demonstrates backend and frontend integration, database management, and CRUD operations using modern software engineering practices.

---

## Overview

The system provides functionalities for managing:

- Students Information
- Courses Management
- Student Enrollment
- Course Registration
- Database Relationships
- Administrative Operations

---

## Features

- Add, Edit, Delete Students
- Add, Edit, Delete Courses
- Student Course Enrollment
- Relational Database Management
- Responsive User Interface
- Form Validation
- Clean MVC-Based Structure
- Database Connectivity

---

## Getting Started

### Prerequisites

Before running the project, make sure you have installed:

- Visual Studio
- .NET SDK
- SQL Server
- SQL Server Management Studio (SSMS)

---

## Installation

Clone the repository:

```bash
git clone https://github.com/farah2543/CoursesAndStudentsManagmentSystem.git
```

Navigate to the project directory:

```bash
cd CoursesAndStudentsManagmentSystem
```

Open the solution in Visual Studio.

---

## Database Setup

1. Configure the database connection string inside:

```json
appsettings.json
```

2. Apply database migrations:

```bash
Update-Database
```

---

## Run the Application

Run the project using Visual Studio or execute:

```bash
dotnet run
```

The application will start locally on:

```bash
https://localhost:xxxx/
```
